# Работа с JSON-базой

Сборка `table 2026-09-15 reopen-last-json` использует JSON как источник данных. Все листы, названия, значения ячеек, объединения, история изменений, складские движения и инвентаризация сохраняются в одном файле.

1. Нажмите «Открыть проект» и выберите JSON. Старые проекты с несколькими листами поддерживаются и без поля `sheetCount`.
2. Разрешите браузеру запись в файл. Изменения автоматически записываются в открытый JSON каждые 5 минут. Непрерывное редактирование не откладывает этот срок. Время последней успешной записи показано вверху таблицы. Ввод внутри ячейки сначала подтвердите Enter или переходом в другую ячейку; автосохранение не закрывает редактор и не двигает курсор.
3. Перед переносом или закрытием нажмите «Сохранить проект» и дождитесь сообщения «JSON … сохранён … Можно переносить файл». Если во время записи появились новые изменения, сохраните ещё раз.
4. Перенесите сохранённый файл на другой компьютер и откройте его через «Открыть проект».

Автосохранение работает после открытия файла с правом записи или первого «Сохранить проект как…». Если доступ не предоставлен, нажмите «Разрешить автосохранение». При ошибке записи или конфликте внешних изменений автосохранение приостанавливается: причина показана на экране, текущие изменения остаются в таблице. После устранения причины можно нажать «Повторить автосохранение» или сохранить отдельную копию.

Если браузер вместо записи скачивает файл, автоматическая перезапись выбранного JSON недоступна: сохраняйте вручную и берите последнюю копию из папки загрузок. Автоматические загрузки каждые 5 минут не создаются. «Скачать JSON» также создаёт копию; открытый исходный файл эта кнопка не обновляет.

При переводе вкладки в фон выполняется дополнительная попытка сохранить изменения. Спящая вкладка, закрытый браузер или выключенный компьютер не могут выполнять периодическое сохранение; при аварийном закрытии могут потеряться изменения после последней успешной записи. Данные базы не дублируются в локальное хранилище браузера.

При следующем запуске приложение заново читает последний открытый или сохранённый через «Сохранить проект как…» файл. Если доступ сохранился, база открывается автоматически. Если браузер требует разрешение, появится карточка с именем файла и кнопкой «Открыть последний JSON»: разрешите доступ, искать файл в папках заново не нужно. Если браузер предлагает постоянный доступ, его можно разрешить для следующих запусков.

Пока последний файл не открыт, вместо пустой таблицы показывается его карточка. При удалении или перемещении файла используйте «Открыть проект» для выбора актуального JSON. Если браузер не поддерживает запоминание файлов или разрешает только обычную загрузку через поле выбора файла, он сможет запомнить лишь имя: выбрать JSON потребуется снова.

В браузере хранятся только файловая ссылка (IndexedDB) и её служебные метаданные: имя файла, идентификатор ссылки и признак успешного запоминания. Содержимое базы, названия листов, ячейки и история в эти хранилища не записываются. При каждом открытии они заново читаются из JSON. Ошибка запоминания показывается явно; приложение не подставляет предыдущую базу вместо последней выбранной.

Если JSON изменили вне текущей вкладки, сохранение поверх него блокируется. Можно открыть свежую версию или записать свои изменения под другим именем через «Сохранить проект как…». Открытие не объединяет две базы.

Кнопка «Скачать прежнюю копию браузера» появляется, если от старой версии сохранились локальные данные. Она выгружает их в `browser-backup.json`, не заменяя открытый проект. Эту копию можно затем открыть как обычный JSON. Старая копия автоматически не загружается и не удаляется.

На другой компьютер переносите всю обновлённую папку приложения: `index.html`, `styles.css`, `script.js`, `stock-service.js`, `project-file-service.js`, а также ваш JSON. Онлайн-загрузка базы в этом режиме убрана.
